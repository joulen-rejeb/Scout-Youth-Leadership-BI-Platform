# Scout BI Platform

End-to-end Business Intelligence & Predictive Analytics platform for scout management and decision support.

## Features

- ETL pipelines and multi-source data integration
- Interactive Power BI dashboards and KPI monitoring
- Predictive analytics and forecasting models
- Workflow automation with n8n
- MLOps pipeline with MLflow
- Dockerized deployment
- Monitoring with Prometheus & Grafana

- React
